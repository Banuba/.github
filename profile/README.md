# Banuba

Banuba builds augmented reality and video SDKs for iOS, Android, Web, Flutter, React Native, Unity and desktop.

## Products

**Face AR SDK** — real-time face tracking, AR face filters, virtual makeup, beautification, background removal and hand-gesture tracking.

→ [Docs](https://docs.banuba.com/far-sdk) · [Product page](https://www.banuba.com/facear-sdk/face-filters)

**Video Editor SDK** — white-label video editing UI with multi-track timeline, AI clipping, AI captions, templates, drafts and effects.

→ [Docs](https://docs.banuba.com/ve-pe-sdk) · [Product page](https://www.banuba.com/video-editor-sdk)

**Photo Editor SDK** — photo editing with filters, beautification, background removal and stickers.

→ [Product page](https://www.banuba.com/photo-editor-sdk)

**TINT Virtual Try-On** — try-on widget for glasses, jewelry, hats, scarves, lenses and eyelashes.

→ [Product page](https://www.banuba.com/solutions/e-commerce/virtual-try-on)

## In production

- **b.stage** (bemyfriends, Korea) — Face AR SDK powers beauty effects and face filters in live streaming and video chat. Passed 1 million monthly active users across 224 countries in two years.

- **MNFST** — face filters in an influencer-marketing app that reached 1 million downloads.

## Requirements

iOS 15.0+ · Android API 24+ · modern browsers for WebAR (WebAssembly). A free trial token is required to run the samples — request one at [banuba.com](https://www.banuba.com).
